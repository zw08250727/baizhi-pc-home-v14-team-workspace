# 联系人一级目录迁移

联系人工作台由 v13 的团队原型迁移到 v14 知识库导航，统一复用当前工作台外壳与版型入口。

## 版型与数据隔离

- 个人版使用 `personal` 空间，标题显示「我的联系人」。
- 团队工作区使用 `team` 空间，标题显示「团队联系人」。
- 企业版使用 `enterprise` 空间，标题显示「企业联系人」。
- 三个空间共用联系人 UI，但通过 `baizhi-v14-contacts` 的空间键隔离联系人、备注和跟进任务。

## 已迁移交互

- 一级目录入口：知识库 → 联系人。
- 联系人搜索、需关注/最近互动/高频筛选。
- 联系人卡片与详情页：概览、时间线、承诺、主题、记忆五个页签。
- Wise AI 关系摘要与预置问答入口。
- 添加备注、添加联系人、JSON 导入联系人。
- 创建跟进任务并持久化到当前版型空间。

## 边界

当前仍是本地原型数据，未连接通讯录、身份、组织权限或真实 Agent 服务。生产实现需要把 `ContactsModel` 的本地读写替换为服务端接口，并沿用当前登录用户与团队权限过滤。
