# 应用数据编辑回写

沿用 v13 已有交互：双击或 Enter 编辑单元格；Enter / 失焦保存；Esc 取消；新增记录抽屉；单条删除确认。保留当前目录、团队视图、筛选和下载。

普通成员只读。表 owner、当前团队创建人/获授权 admin，以及企业管理范围内的管理员可维护可见记录；系统字段不可编辑。权限在模型写入口再次校验。

实现顺序：迁移字段校验和编辑器 → 接入当前 AppsDataModel 的增删改 → 集成表格和草稿保护 → 验证权限、刷新持久化、并发版本和失败恢复 → 部署。

本静态原型写入统一 localStorage Apps 数据库；不连接真实 Apps API。写入使用记录版本校验，校验失败或存储失败保留草稿，手工操作留存独立审计信息，不伪造 Agent 执行。
